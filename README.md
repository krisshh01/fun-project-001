# 🎣 Catfish Guessing — Tinder Training Game

A satirical, fast-paced dating app simulator designed to test your instincts against online scammers, bots, and catfish profiles built in a single HTML file with CSS and JavaScript.

---

## 🛠️ Status: In Active Development

> ⚠️ **Note:** This game is currently in active development. New profile templates, satire ads, and roast scenarios are continuously being added! Feedback and feature suggestions are welcome.

---

## ✨ Features

* 📱 **Authentic Tinder UX**: Clean mobile interface complete with swipe cards, live stats, and custom sound effects.


* 🎣 **Spot the Scammer**: Analyze bios and photos to identify IG follower farmers, crypto scammers, fake models, and romance traps.


* 🔥 **Savage Roast Engine**: Get humorous, custom roasts and explanations whenever you fall for a scammer's profile.


* 🏆 **Ranking System**: Build your streak to progress from *Freshly Catfished* to *Certified Catfish Detective*.


* 🚨 **Retro Ad Satire**: Features sketchy fake side banner ads for full desktop immersion.
